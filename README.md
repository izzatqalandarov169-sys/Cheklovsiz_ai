# Cheklovsiz AI 🚀

API'ga bog‘lanmagan, o‘z serverida ishlaydigan AI platformasi uchun boshlang‘ich loyiha.

## Reja

- 💬 Chat interfeysi
- 🎬 Text-to-video modul
- 🖼️ Image-to-video modul
- 🔌 O‘z backend API
- 📁 Generatsiya tarixini saqlash
- 🌐 Chrome/web interfeys

> Video generatsiya sifati va tezligi ishlatiladigan model hamda mavjud GPU resursiga bog‘liq.

## Tuzilishi

```text
frontend/   Web interfeys
backend/    O‘z API va AI servislar
models/     Local model konfiguratsiyasi
storage/    Generatsiya qilingan fayllar
```

## Ishga tushirish

Hozircha bu repository loyiha skeleti hisoblanadi. Keyingi bosqichlarda backend va local AI model integratsiyasi qo‘shiladi.
